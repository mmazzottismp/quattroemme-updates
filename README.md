# quattroemme · canale di aggiornamento

Questo repository non contiene codice sorgente: è lo **scaffale** da cui i siti costruiti con il tema e i blocchi *quattroemme* scaricano gli aggiornamenti.

Pubblicato con GitHub Pages su <https://mmazzottismp.github.io/quattroemme-updates/>.

## Com'è organizzato

```
stabile/     i file che descrivono l'ultima versione del canale stabile
pilota/      gli stessi file per il canale pilota, che riceve le novità per primo
zip/         i pacchetti, tutti, anche quelli vecchi
```

I pacchetti vecchi **non si cancellano mai**: sono l'unico modo per tornare indietro se una versione esce difettosa.
